# JS Calculator

A simple and stylish calculator built using **HTML, CSS, and JavaScript**.  
This project demonstrates DOM manipulation, event handling, and responsive design. Perfect for beginners learning web development.

---

## Features

- Basic arithmetic operations: `+`, `-`, `*`, `/`
- Clear (`C`) button to reset input
- Decimal support (`.`)
- Interactive and responsive button design
- Stylish colors for numbers, operators, equal and clear button

---

# Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## How to Use

1. Open `calculator.html` in any modern browser.
2. Click the buttons to input numbers and operators.
3. Press `=` to calculate.
4. Press `C` to clear.
